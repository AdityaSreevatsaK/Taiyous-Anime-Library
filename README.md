# Taiyou's Anime Library

A standalone **React + TypeScript anime catalogue and episode-tracking prototype**. The shipped prototype provides an interactive, **entirely synthetic** catalogue hosted as a public Cloudflare Pages site. It is not an authenticated/private cloud application.

## Implemented in the first milestone
- Search by series title or alias; genre and watch-status filters.
- Series detail, seasons, episode checkboxes, specials and OVAs.
- Immutable progress commands keyed by opaque episode IDs; no last-episode inference.
- Manually controlled planned / watching / paused / completed / dropped status.
- Local-only personal rating, comment, tag and collection controls.
- Explicit missing/unknown totals and distinct re-release IDs.
- Unit tests for identity and watch transitions, plus responsive styles.

**Important:** All titles, comments and watched sets are synthetic. Browser changes are held only in React memory and reset on refresh. No private data, authentication, provider API, video player, real cover art or cross-device synchronisation is connected. The hosted public demo is **not** a private production data service.

## Public Cloudflare Pages demo (fictional data only)

**Live app:** https://taiyous-anime-library.pages.dev/

Cloudflare Pages uses its **GitHub Git integration** to build `master` with `npm run build`, publish `dist` and create branch previews. GitHub Actions remains the independent typecheck/unit/browser-test gate, **not** the Cloudflare deployer. A new commit on `master` may trigger a production Cloudflare build; Cloudflare deployment is not automatically gated on GitHub Actions success. See [deployment/preview runbook](docs/DEMO_PREVIEW.md).

All catalogue records are fictional, and user edits reset on refresh. Do **not** import private anime/watch histories or credentials into the public Vite build.

## Start locally
Requires Node.js 22+. Clone the repository, then run:

~~~sh
npm ci
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run dev
~~~

The dependency lockfile was generated by a real Node.js 22 GitHub Actions install and is committed for reproducible `npm ci` builds. Browser E2E tests use Playwright Chromium. CI results are checked per commit and do not imply a live deployment.

## Key files
- `src/domain/types.ts`: current TypeScript domain draft, not a persisted schema
- `src/domain/episodes.ts`: identity, ordering and collision checks
- `src/domain/progress.ts`: pure progress transformations and derived counts
- `src/data/catalogue.ts`: fictional fixtures only
- `src/App.tsx`, `src/styles.css`: mobile-responsive local demo
- `docs/adr/`: proposals requiring owner decisions before live integration

## Safety and ecosystem
This repo owns anime only. No changes to Novel, Manga, Movies & TV, or Shared Core. The hub is optional; the app runs by itself. No credential in `VITE_*`, no private data in the public Cloudflare build and no scraping, streaming or DRM circumvention. Git-connected Cloudflare deployments may be automatic for merged commits; they do not imply approval to enable real private services. Public source code does not imply public personal data.
